# Κλάδος `working` — Κατάσταση 2026-07-17

Συγκεντρωτικός κλάδος που περιέχει όλες τις επιτυχημένες τοπικές διορθώσεις πάνω στο

Σκοπός του κλάδου: ένα λειτουργικό, επικαιροποιημένο (patched) opencode build που
αντιμετωπίζει τρεις κατηγορίες προβλημάτων που παραμένουν ανοιχτά upstream —
**τρεμούλιασμα του TUI**, **υψηλό φορτίο CPU κατά τη ροή (streaming)** και **διαρροές
μνήμης από μη ντετερμινιστική αποδόμηση SSE**. Περιέχει επίσης τα patched.47–57 binaries
και την υποδομή profiling με την οποία μετρήθηκαν αυτές οι διορθώσεις.

Τα commits παρακάτω είναι ομαδοποιημένα κατά θέμα· εντός κάθε ομάδας η σειρά είναι
χρονολογική. Τα build-commits (`chore(opencode): build patched.N`) αναφέρονται εν συντομία
μόνο στο τέλος, αφού δεν περιέχουν αλλαγές λογικής.
